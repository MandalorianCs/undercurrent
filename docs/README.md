# docs/

Отсюда GitHub Pages раздаёт сайт.

## Один файл, две роли

`index.html` — и сайт, и презентация.

| Адрес | Что показывает |
|---|---|
| `/` | Лендинг: продукт, механика, тарифы, рынок |
| `/#pitch` | Презентация для демо-дня: 13 слайдов, тайминг 180 с |

Переключение — кнопка «Презентация» в шапке или адрес с `#pitch`.
Ссылкой на `#pitch` можно поделиться: она откроет сразу презентацию.

В режиме презентации: **←/→** листать, **Esc** вернуться на сайт,
**T** таймер, **F** во весь экран. На телефоне — свайпом.

## Почему один файл, а не три

Раньше было три: лендинг, питч и диаграмма отдельно. Это три ссылки,
три копии палитры и три места, где правда может разойтись. Достаточно
один раз поправить тариф на лендинге и забыть про питч, чтобы показать
инвестору одну цифру, а клиенту другую.

Диаграмма разреза схемы теперь встроена прямо в секцию про порог
анонимности — там, где о ней и идёт речь.
