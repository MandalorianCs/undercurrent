# docs/

Отсюда GitHub Pages раздаёт сайт.

| Что | Где |
|---|---|
| Лендинг | `index.html` — один самодостаточный файл |
| Заметки для разработки | `dev/` |

## Про единственную копию

`index.html` — **источник правды** для сайта. Раньше он лежал вне
репозитория, в папке «Сайт презентация приложение», и не имел ни
истории, ни возможности откатиться.

Та копия оставлена как снимок на момент переноса. Править её больше не
нужно: две копии одного сайта разъедутся так же тихо, как две копии
любого другого правила, и разница обнаружится в момент, когда кто-то
покажет инвестору не ту версию.
